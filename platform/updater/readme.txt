Majora's Mask VR - FullDiveGames private preview

Windows: unpack the whole ZIP, including assets, into its own folder. On first
launch, follow 2Ship's extraction prompt and select your own uncompressed ROM.
Alternatively, place an existing matching mm.o2r beside 2ship.exe.
Start Play Majoras Mask VR.cmd while connected to your OpenXR headset runtime.

Right-stick click opens the VR menu. Triggers switch tabs. System includes
Check updates and Install available update. The initial local preview has
no public feed configured; it reports that honestly. A configured feed lives
in update-feed.json beside 2ship.exe as {"url":"https://.../latest.json"}.
Only use the dedicated FullDiveGames Majora's Mask feed once published.

Updates retain mm.o2r, saves, mods and settings. The game closes only after a
verified update is staged, then restarts. Replaced app files are backed up in
updates/rollback. Do not delete saves or uninstall the Quest app to update it.

Standalone Quest: install the paired APK and launch Majora's Mask VR from
Unknown Sources. Choose your own ROM in the system file picker (Downloads or
another folder); it extracts on the headset. US 1.0 and US GameCube ROMs in
z64/v64/n64 byte order are supported. Importing an existing mm.o2r is also
available. The ROM stays local and the original file is not changed.
Quest updates ask for Android's install permission and confirmation and use
the same signing identity. PC and Quest versions share the native VR systems.
Device parity, sustained 120 FPS and full campaign completion remain unverified.
