## v2.3 - Interaction and settings update

- Improved hot-spring water and bug bottle pickup, with bottle and Goron Elder safeguards.
- Fixed repeated save-state verification stalls with large texture packs.
- Added 2Ship settings search and Items and masks options, including Persistent Bunny Hood and Blast Mask cooldown; improved menu navigation.
- Added adjustable sword/Goron fist hitboxes and physical magic great spin.
- Added left/right-hand HUD attachment and sizing, retaining opacity controls.
- Added a 120 FPS cap alongside 72/80/90; Uncapped now allows runtime-supported rates above 120 Hz.

Make an ordinary game save before updating. Exact save states still require the matching build and content. Large packs need an initial background verification before saving or loading states. This remains a beta; not every game scenario or mod combination has been verified.
